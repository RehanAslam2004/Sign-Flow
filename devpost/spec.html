Hybrid Client-Server Architecture • In-Browser MediaPipe + Python FastAPI WebSocket Inference

System Architecture Diagram

Key Separation: Video frames stay 100% inside the browser. MediaPipe JS extracts 21 points, and numeric coordinates are streamed via WebSocket to the Python service, which owns canonical feature normalization and model inference.

Versioned WebSocket Schema (v1.0)

Component Architecture & Responsibilities

Next.js / React

CameraViewport.tsx

Initializes webcam with requested facingMode (front/rear), renders framing guide, and binds video to MediaPipe extractor.

TypeScript / WebAssembly

lib/mediapipe.ts

Loads HandLandmarker model asset, tracks hands at ~30 FPS, and sends raw landmarks without client-side normalization.

Python / FastAPI

cv-service/preprocessing.py

Single source of truth for wrist-centering and palm-scale normalization. Shared between training pipeline and live server.

TypeScript Logic

lib/stateMachine.ts

500–800ms stability window + gesture boundary detection. Eliminates duplicate repeats and triggers speech synthesis.

Single Development Command

A single cross-platform command launches both services with live reload:

npm run dev
